# Developer Guide & Build Setup

This guide provides instructions for building, running, and extending Penstock.

## Prerequisites
- macOS or Linux
- Apple Clang or GCC with C99 support
- Python 3.9 or newer
- Standard Make

## Quick Start

    git clone https://github.com/Aneesh495/penstock.git
    cd penstock
    make
    make test
    make demo
